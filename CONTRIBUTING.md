# Contributing to LingXi T3

This repository (`LingXiFox/t3code`) is an independent personal fork of [T3 Code](https://github.com/pingdotgg/t3code), maintained by [LingXiFox](https://github.com/LingXiFox).

- **Pull requests for LingXi T3** should target the `lingxifox` branch (never `main`, which stays a clean mirror of `pingdotgg/t3code` `main`).
- **Upstream T3 Code bugs, features, and PRs** belong on [`pingdotgg/t3code`](https://github.com/pingdotgg/t3code), not here.
- **Fork-specific bugs** (identity isolation, update channels, release/sync automation, or LingXi-specific changes) can be reported in [LingXiFox/t3code Issues](https://github.com/LingXiFox/t3code/issues).
